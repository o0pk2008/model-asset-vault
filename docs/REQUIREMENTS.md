# ModelVault 在线版需求说明

本文档是在原始需求基础上补充完善后的版本，标注 **[补充]** 的条目是原始需求没有明确提到、但上线运营需要的内容。

## 1. 目标

把本地局域网版「模型资产库」改为互联网可访问的在线平台：

| 项目 | 方案 |
| --- | --- |
| 部署平台 | Vercel（Python / Flask Serverless Functions + CDN 托管静态页面） |
| 数据库 | Vercel Marketplace 中的 **Neon Postgres** 免费套餐（0.5 GB，足够存放元数据） |
| 文件存储 | 你的 **AWS S3** 存储桶（参考照片、制作截图、GLB 模型） |

保留原有的业务流程：发起人创建任务（上传参考照片）→ 制作人提交成果（制作截图 + GLB）→ 上传 GLB 后自动变为“已完成”→ 所有人在线预览和下载。

## 2. 账号注册与登录

- 用户名 + 密码登录。用户名 3–32 位小写字母/数字/`_`/`.`/`-`，不区分大小写。
- 密码至少 8 位且同时包含字母和数字；使用 scrypt 加盐哈希存储。
- 登录态使用签名的 HttpOnly Cookie，默认 7 天有效。
- **[补充] 防暴力破解**：同一账号连续 5 次密码错误，锁定 15 分钟；管理员可手动解锁。
- **[补充] 注册方式由管理员控制**：开放注册 / 注册需审核 / 关闭注册（仅管理员创建账号）。
- **[补充] 个人账号设置**：修改显示名称、修改密码（修改后其它设备的登录自动失效）。
- **[补充] 首个管理员**：通过环境变量 `ADMIN_USERNAME` / `ADMIN_PASSWORD` 在首次启动时自动创建，避免“谁先注册谁是管理员”的安全问题。

## 3. 权限管理

| 权限 | 默认账号 | 说明 |
| --- | :---: | --- |
| 查看资产 / 在线预览 | ✅ | 所有已登录的启用账号 |
| 下载 GLB | ✅ | 所有已登录的启用账号 |
| **创建任务** | ❌ | 单独授权。可新建任务并上传参考照片；可修改**自己创建的**任务的基础信息和参考照片 |
| **[补充] 编辑 / 提交成果** | ❌ | 单独授权。可编辑任意任务、上传制作截图与 GLB（制作人需要此权限） |
| **删除任务** | ❌ | 单独授权。删除任务时会同时删除 S3 中的相关文件 |
| 管理员 | — | 拥有以上全部权限，并可进入管理后台 |

> 为什么增加“编辑 / 提交成果”权限：原流程中制作人需要给任务补充 GLB。如果只有“创建”和“删除”两种权限，制作人要么无法提交成果，要么必须拥有创建权限，所以把它拆成独立权限，三者可以任意组合。

- 权限在服务端逐个接口校验，前端只是隐藏无权限的按钮。
- 权限变更立即生效（每次请求都会读取最新权限）；停用账号会立即使其登录失效。

## 4. 管理后台（`/admin.html`，仅管理员）

1. **概览**：用户数（启用/停用/待审核）、资产数、已完成数、GLB 总大小、数据库与存储状态、最近操作。
2. **用户管理**
   - 搜索、按状态筛选（待审核 / 已启用 / 已停用）
   - 新建用户（可直接设定权限和管理员身份，默认生成随机初始密码）
   - 三个权限开关独立控制
   - 审核通过、启用 / 停用、设为 / 取消管理员、重置密码、解锁、删除
   - **[补充] 安全约束**：不能停用、删除自己或取消自己的管理员身份；系统中至少保留一名启用的管理员
3. **存储设置（AWS S3）**
   - 填写 Bucket、Region、Access Key ID、Secret Access Key、路径前缀、访问链接有效期，以及可选的 S3 兼容 Endpoint
   - Secret Key 使用 `SECRET_KEY` 派生的密钥加密后存数据库，界面只显示末 4 位
   - **[补充]** 测试连接（读写删一次探针文件）、一键写入存储桶 CORS 规则
   - **[补充]** 存储用量统计（按文件类型）、孤立文件检测与清理（上传后未保存 / 已被替换的文件，超过 24 小时才会清理）
   - **[补充]** 展示最小权限 IAM 策略示例
4. **系统设置**：注册方式。
5. **[补充] 操作日志**：登录 / 登录失败 / 注册、任务创建 / 编辑 / 删除 / 下载、所有后台配置变更，含操作人、IP 和时间，可搜索、分页。

## 5. 文件上传与访问

- **[补充] 浏览器直传 S3**：Vercel 函数的请求体上限约 4.5 MB，GLB 可能上百 MB，因此由服务端签发**预签名 POST**，浏览器直接上传到 S3，并显示上传进度。
- 上传限制：图片 ≤ 50 MB，GLB ≤ 1 GB（可通过 `MAX_GLB_MB` 调整），由 S3 上传策略和保存时的服务端校验双重保证。
- 存储桶保持**私有**。预览图和模型使用带签名的临时链接（默认 12 小时）；签名时间按 6 小时取整，同一文件的链接在一段时间内保持不变，浏览器可以缓存，减少 S3 流量费。
- 下载经过 `/api/assets/{id}/download`：先校验登录、写下载日志，再 302 跳转到带 `Content-Disposition` 的签名链接，保留中文文件名。

## 6. 非功能需求

- **安全**：HttpOnly + SameSite=Lax Cookie；所有写操作要求自定义请求头（防 CSRF）；接口统一鉴权；S3 密钥加密存储。
- **中英文界面**：沿用原有的语言切换，新增页面同样支持。
- **本地开发**：未配置 `DATABASE_URL` 时使用 SQLite；未配置 S3 时使用本地磁盘（仅本地，Vercel 上必须配置 S3）。
- **数据迁移**：提供 `scripts/migrate_local.py` 把旧版 `data/assets.sqlite3` 和 `data/uploads/` 迁移到线上。

## 7. 暂不包含（可作为后续迭代）

- 邮箱验证、找回密码邮件（需要额外的邮件服务；目前由管理员重置密码）
- 第三方登录（企业微信 / 飞书 / Google 等）
- 按项目或分类划分的细粒度数据权限
- 分片上传（> 5 GB 的单文件）
