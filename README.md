# 模型资产库

基于 SQLite 的本地局域网 3D 模型资产管理工具，围绕“发起人建任务、制作人补成果”的两阶段流程设计。支持参考照片、制作截图和 GLB 文件的粘贴/上传、表格管理、状态流转与 3D 预览。无需登录，开箱即用。

## 启动

在 Windows 上双击 `start.bat` 即可。首次运行会自动创建 Python 虚拟环境并安装依赖。

启动后终端会显示两个地址：

- 本机访问：`http://127.0.0.1:8765`
- 局域网访问：`http://<本机局域网IP>:8765`

同一局域网内的其他设备使用局域网地址即可访问。若无法访问，请确认 Windows 防火墙已允许 Python / 8765 端口。

也可以手动运行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

## 协作流程

1. **发起人建任务**：点击“新增资产”，填写名称、编号、发起人等信息，粘贴参考照片后保存。条目默认进入“待制作”。
2. **制作人补成果**：在待制作任务中点击该行的“编辑”，会自动进入成果录入视图：左侧查看参考照片和要求，右侧填写制作人、上传制作截图与 GLB。上传 GLB 后状态自动变为“已完成”，无需手动选择。面板顶部可随时切换“基础信息 / 制作成果”。
3. **查看与交付**：点击行内的“预览模型”按钮查看 3D 模型，点击“下载 GLB”获取原始文件。状态筛选只有“全部 / 待制作 / 已完成”三种。

## 功能

- 状态自动流转：新建任务为“待制作”，上传 GLB 后自动变为“已完成”
- 成果录入视图只展示制作所需内容，不会覆盖发起人填写的信息
- 记录发起人和制作人，便于局域网内多人协作追溯
- 新增、编辑、删除、搜索、筛选和排序模型资产
- 新建时自动按上一条记录递增名称与编号，并继承上一条的分类
- 剪贴板粘贴图片（`Ctrl` + `V`），可指定粘贴到参考照片或制作截图
- 选择或拖拽上传 GLB 文件，支持剪贴板中的 `.glb` 文件
- 表格缩略图展示、GLB 文件信息展示、下载原始文件
- 点击预览按钮进入分栏预览：左侧参考照片、右侧 3D 模型，中间分隔线可拖拽调整宽度
- 3D 预览使用内置中性影棚 HDR 光照 `static/env/studio.hdr`，无颜色干扰，无需外网
- 统计资产总数、待制作数量、已完成数量和模型总大小
- 表格 / 卡片两种查看模式，卡片内嵌可自动旋转、可用鼠标操作的 GLB 模型预览
- 中文 / 英文界面一键切换，语言选择会自动保存
- 表格图片点击可放大查看，列表行和缩略图更大

## 数据存储

- SQLite 数据库：`data/assets.sqlite3`
- 上传文件：`data/uploads/`

请定期备份 `data/` 目录。数据库在首次启动时自动创建。

## 配置

可通过环境变量调整监听地址和端口：

```powershell
$env:ASSET_PORT = "9000"
$env:ASSET_HOST = "0.0.0.0"
python app.py
```
